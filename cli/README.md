Описание: 
Программа написана на Java и работает в консольном режиме. В проекте реализована виртуальная файловая система VFS, которая загружается в память. Все изменения файловой системы происходят только в памяти и не изменяют реальные файлы на компьютере.  
  
В программе реализованы следующие возможности:  
- интерактивный режим работы;  
- обработка команд пользователя;  
- раскрытие переменных окружения, например "$HOME";  
- загрузка виртуальной файловой системы;  
- выполнение команд из стартового скрипта;  
- логирование команд в XML-файл;  
- работа с файлами и каталогами в виртуальной файловой системе.  

---

Описание основных классов:

Main
Является точкой входа в программу.  

Основной метод:  
public static void main(String[] args)  
  
В этом методе происходит запуск программы. Также из аргументов командной строки получаются параметры, необходимые для работы приложения.  
  
Поддерживаются следующие параметры:  
- "--vfs" указывает путь к исходной директории виртуальной файловой системы.  
- "--log" указывает путь к файлу логов.  
- "--script" указывает путь к стартовому скрипту.  
  
---  
  
Shell
Отвечает за основную работу консольной оболочки. Он получает команды от пользователя, передаёт их на обработку и выводит результат.  
  
Основной метод:  
run()  
  
Метод запускает интерактивный режим. Пользователю показывается приглашение для ввода команды.  
  
Пример:  
vfs:/$  
  
Метод выполнения команд.  
executeCommand(String input)  
  
Этот метод получает строку с командой, разбирает её и запускает нужную команду.  
  
Например, если пользователь ввёл "ls", то вызывается логика команды "ls".  
 
Если команда не существует, выводится сообщение об ошибке.  
  
---  
  
CommandParser
Используется для обработки введённой пользователем команды.  
  
Основной метод:  
parse(String input)  
  
Метод разделяет строку на название команды и её аргументы.  

Например:  
wc -l file.txt  
  
После обработки получается:    
Команда: wc  
Аргументы: -l, file.txt  
  
Также парсер поддерживает переменные окружения.  
  
Например:  
cd $HOME  
  
Переменная "$HOME" заменяется на её значение из операционной системы.  
  
Для поиска переменных используется "Pattern" и "Matcher".  
  
---  
  
Vfs  
Представляет виртуальную файловую систему. Виртуальная файловая система существует только в памяти программы. 
  
Основные методы класса:  
load(Path source)  
  
Метод загружает структуру файлов и каталогов из указанной физической директории. После загрузки создаётся копия структуры в памяти. Реальные файлы после этого не изменяются.  
  
resolve(String path) ищет файл или каталог по указанному пути.  
  
Например:  
/home/user/file.txt  
  
Если объект найден, метод возвращает объект виртуальной файловой системы.  
  
changeDirectory(String path) изменяет текущую директорию. Он используется при выполнении команды "cd". Перед переходом проверяется, существует ли каталог и является ли найденный объект директорией.  
  
remove(String path, boolean recursive) удаляет файл или каталог из виртуальной файловой системы. 

Если удаляется каталог, параметр "recursive" определяет, разрешено ли его рекурсивное удаление.  
  
Например:  
rm file.txt  
  
удаляет файл, а:  
rm -r directory  
  
удаляет каталог вместе с его содержимым, только в памяти программы. 

contains(VfsDirectory directory, VfsDirectory target) проверяет, является ли указанная директория родительской для другого каталога. Он используется для защиты текущей директории от удаления.  
  
Например, если текущая директория находится по пути: "/home/user", то программа не должна разрешить удалить "/home", так как текущая директория находится внутри неё.  
  
---  
  
VfsNode  
  
Является базовым классом для объектов виртуальной файловой системы.  
  
От этого класса наследуются:  
- "VfsDirectory";  
- "VfsFile".  
  
Общие свойства объектов:  
- имя;  
- родительский каталог.  
  
---  
  
VfsDirectory  
  
Представляет каталог, может содержать другие каталоги и файлы.  
  
Основные методы:

- addChild(VfsNode node) - Добавляет файл или каталог в текущую директорию.  
- removeChild(String name) - Удаляет объект из текущего каталога по имени.  
- getChildren() - Возвращает содержимое текущей директории. Этот метод используется, например, командой "ls" для получения списка файлов и каталогов.  
  
---  
  
VfsFile  
  
Представляет файл в виртуальной файловой системе, что хранит своё содержимое в памяти.
  
Основной метод:  
getContent() - Возвращает содержимое файла.  
  
Этот метод используется командой "wc", которая подсчитывает количество строк, слов и байтов в файле.  
  
---  
  
XmlCommandLogger  
Отвечает за логирование команд.  
  
Основной метод записывает информацию о выполненной команде в XML-файл.  
  
В лог записываются:  
- дата и время;  
- имя пользователя;  
- название команды;  
- аргументы команды.  
  
Пример записи в XML:  
```
<event>  
<timestamp>2026-10-31T12:00:00</timestamp>  
<user>user</user>  
<command>ls</command>  
<arguments>-l</arguments>  
</event>  
```
Описание команд:  

- ls  - Команда выводит содержимое текущей директории или указанного каталога.  

Пример:    
vfs:/$ ls  
home  
file.txt  
  
- cd - Команда изменяет текущую директорию.  
  
Пример:  
vfs:/$ cd /home  
  
- uname - Команда выводит информацию об операционной системе.  
  
Пример:    
vfs:/$ uname  
Linux  
  
wc -Команда подсчитывает информацию о файле.  

Например:    
vfs:/$ wc file.txt  
3 15 84 file.txt  
  
- tree - Команда выводит структуру файловой системы в виде дерева.  
  
Пример:  
vfs:/$ tree  
home  
└── user  
└── file.txt  
  
- rm - Команда удаляет файл или каталог из VFS.  
  
Пример удаления файла:  
rm file.txt  
  
Для удаления каталога используется рекурсивный режим:  
  
rm -r directory   
  
- exit - Команда завершает работу программы.  
  
Пример:  
vfs:/$ exit

**Запуск программы**

Запуск программы с VFS:  
``./gradlew run --args="--vfs ./test-vfs/deep"  ``
  
Запуск со стартовым скриптом:  
``./gradlew run --args="--script ./tests/startup-stage5.txt" `` 
  
Запуск с логированием:  
``./gradlew run --args="--log ./logs/commands.xml"  ``
  
Тестовые скрипты  
В каталоге "scripts" находятся Bash-скрипты для проверки работы программы.  
  
Например:    
./scripts/test-all.sh  
  
Скрипты запускают программу с разными параметрами и виртуальными файловыми системами.  
  
В каталоге "tests" находятся стартовые сценарии для самого эмулятора.  
  
Например, файл может содержать:  
ls  
cd /home  
tree  
exit  

Пример работы    
vfs:/$ ls  
home  
file.txt  
  
vfs:/$ cd /home  
  
vfs:/home$ tree  
home  
└── user  
└── document.txt  
  
vfs:/home$ cd /unknown  
Ошибка: каталог не найден.  
  
vfs:/home$ exit  
Завершение работы.  
  
Особенности работы VFS  
Работа файловой системы происходит следующим образом:  
  
Физическая директория -> Загрузка структуры в память -> Виртуальная файловая система -> Работа команд CLI
